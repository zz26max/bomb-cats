| 画面位置 | 当前实现 | 缺什么 |

## 1. 开工前必须先定的三件事

### 1.1 美术风格（三选一，决定后面全部素材的画法）

| 方案 | 描述 | 与现有深色牌桌的匹配度 | 成本 |
|---|---|---|---|
| **A. 扁平厚涂 + 粗描边**（推荐） | 硬边高光、4~6 色、2~3px 深色描边，卡通猫拟人 | 高。深色底上白/金描边最跳 | 低 |
| B. 手绘水彩 / 蜡笔 | 纸质纹理、边缘不规则 | 中。浅色插画压深色底容易脏 | 中 |
| C. 像素 / 16-bit | 32×32 或 64×64 网格 | 高但和现有 96×134 卡片比例与圆角冲突 | 中，需重做 UI |

> 现有配色已固定，素材必须迁就它：`--gold #d9b061`、`--gold-2 #f3d79a`、`--red #e5484d`、`--green #3ccb7f`、`--blue #5b9dff`、`--purple #a879ff`，底色 `#08090d / #0f1219`。
> **凡是素材里出现的「白」，实际要用 `#fff0d0` 暖白**，纯白在深底上会发灰发脏。

### 1.2 卡面做法（影响交付形式）

| 做法 | 说明 | 优点 | 缺点 |
|---|---|---|---|
| **甲：整卡图** | 每张牌一整张 384×536，含边框、名字、说明 | 表现力最强 | 名字/说明被画死，改文案要重画；11 种 × 1 张 = 11 个文件 |
| **乙：插画层 + CSS 卡框**（推荐） | 只画中央插画（透明底），边框/名字/说明仍由 CSS 渲染 | 文案可改、可复用、可 hover 提亮、体积小 | 需要美术留出安全区 |
| 丙：图标版 | 只画 64×88 的小图标，用于弃牌堆/预测未来 | 最省 | 手牌区撑不起来 |

**推荐乙**，另外补一套「丙」的图标用于弃牌堆和小尺寸展示（可从乙的插画直接缩，也可单独简化）。

### 1.3 猫角色差分深度

- **最低配**：5 张头像（正常态）——够用。
- **推荐**：5 张头像 + 5 张「出局/被炸」差分（灰化已由 CSS 处理，差分只换表情与姿势）。
- **满配**：每只猫再加「思考中 / 得意 / 惊恐」3 帧，配合 AI 回合时头像切换。
差分越多越活，但工作量线性增长；建议先做最低配 + 出局共 10 张。

现在 `audio.js` 用 WebAudio 现场合成，**零文件、零加载、零版权风险**，其实已经够用。只有想升级质感时才需要：

## 4. 技术规格（硬约束）

| 项 | 规格 | 原因 |
|---|---|---|
| 位图倍率 | 一律按 **@2x** 出，母版留 1024 宽 | 卡面在 `draw-flash` 里会放大到 116px，且要照顾高 DPI 屏 |
| 格式 | 插画 **WebP**（透明底），图标 **SVG** | 无构建流程，不能转码；WebP 体积约为 PNG 的 1/3 |
| 体积预算 | 全部素材 **≤ 6MB**；单张卡面 ≤ 60KB；桌面底纹 ≤ 150KB | 现在是「双击 HTML 就能玩」，加载要快 |
| 路径 | **相对路径**，全部静态 | `file://` 下不能 fetch、不能 import |
| 透明底 | 卡面插画四周留 12% 安全区 | 三个断点卡片比例 0.716 / 0.712 / 0.70 不完全一致 |
| 深色适配 | 素材本身**不要带白底**；描边用 `#08090d` 系而非纯黑 | 深底上纯黑描边会糊成一团 |
| 加载兜底 | 图片 `onerror` 必须回落到现有 emoji / CSS 渐变 | 丢文件、断网时不能白屏 |
| 动效 | `prefers-reduced-motion` 下静态可读 | 现有 CSS 已处理，新素材不要绕过 |

## 5. 接入点与代码约束（改之前必看）

1. **`CARDS[type].glyph` 不能删。** `tests/integration.test.js:89` 断言每种牌都有 `glyph`，`tests/browser.test.js` 与 `screenshot.js` 也在构造假牌时传 `glyph`。做法：**保留 emoji 作为兜底**，在 `.glyph` 上叠 `background-image`，或新增一个 `<img class="art">` 层并用 `onerror` 隐藏。
2. **卡面文字必须继续渲染。** `integration.test.js` 有「卡面必须渲染出名字与说明」的回归断言。走「乙：插画层」方案时，`.cname` / `.ctext` 保持不动。
3. **`.card-back.mini` 是 22×32（比例 0.69），和 96×134（0.716）不同。** 卡背图用 `background-size: cover` + `background-position: center`，别用精确尺寸。
4. **对手卡只有 132px 宽。** 加头像必然要调 `min-width`，属于布局改动，建议单独一步做，别和素材替换混在一起。
5. **`tests/screenshot.js` 会出验收图**，素材接完直接重跑对比。
6. **弃牌堆现在只显示一个 emoji**（`view.js:144`），要显示缩略卡面需改这一行。
